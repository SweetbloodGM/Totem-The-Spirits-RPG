# Totem - The Spirits' RPG
## Sistema per Foundry Virtual Tabletop - Foundry Virtual Tabletop System

Totem è un GDR Horror narrativo dalle regole semplici e che ti farà rivivere le inquietanti atmosfere ispirate ai classici del tema spiritico, da Poltergeist a Paranormal Activity, passando per The Ring, Insidious, Silent Hill, L’esorcista e molti altri capolavori da incubo.

Totem is a narrative horror RPG with simple rules that will bring back the unsettling atmosphere inspired by classic spirit-themed works—from Poltergeist to Paranormal Activity, from The Ring and Insidious to Silent Hill, The Exorcist, and many other nightmare masterpieces.

Totem condurrà il tuo gruppo di Cercatori in un viaggio da brivido nel mondo soprannaturale, alla ricerca di un contatto con le entità che popolano altri piani della realtà. Vivrai l’esperienza di visitare case infestate, esorcizzare demoni, interrogare una presenza con la tavola degli spiriti e attraversare la soglia più estrema del limbo!

Totem will lead your group of Seekers on a thrilling journey into the supernatural, searching for contact with the entities that inhabit other planes of reality. You will experience haunted houses, demonic exorcisms, séances with a spirit board, and crossing the most extreme threshold of limbo!

## 📋 Caratteristiche - Features

- **Sistema di risoluzione semplice**: Lancia la moneta (Testa = Successo, Croce = Fallimento)

   **Simple resolution system**: Flip a coin (Heads = Success, Tails = Failure)

- **Schede personaggio intuitive**: Interfaccia pulita con tabs per traumi, oggetti e abilità

  **Intuitive character sheets**: Clean interface with tabs for traumas, items, and abilities

- **Bilingue**: Supporto completo per Italiano e Inglese

   **Bilingual**: Full support for Italian and English

- **Foundry VTT v13**: Compatibile con l'ultima versione di Foundry

   **Foundry VTT v13**: Compatible with the latest Foundry version

## 🚀 Installazione - Installation

### Installazione Manuale - Manual Installation

1. Scarica o clona questa repository - Download or clone this repository

2. Copia la cartella `totem-foundry` nella directory dei sistemi di Foundry: - Copy the `totem-foundry` folder into Foundry’s systems directory:
   - **Windows**: `%localappdata%/FoundryVTT/Data/systems/`
   - **macOS**: `~/Library/Application Support/FoundryVTT/Data/systems/`
   - **Linux**: `~/.local/share/FoundryVTT/Data/systems/`

3. Rinomina la cartella in `totem` (se necessario) - Rename the folder to `totem` (if needed)

4. Riavvia Foundry VTT - Restart Foundry VTT

5. Crea un nuovo mondo e seleziona **Totem - The Spirits' RPG** come sistema di gioco - Create a new World and select **Totem - The Spirits' RPG** as the game system

### Installazione tramite Manifest - Manifest Installation

Puoi installare Totem direttamente da Foundry usando questo manifest URL: - You can install Totem directly from Foundry using this manifest URL:
```
https://github.com/SweetbloodGM/Totem-The-Spirits-RPG/releases/latest/download/system.json

```
